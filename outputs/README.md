# outputs/

Curated paper-facing summaries and review artifacts.

## Artifact Status

| Status | Artifact classes | Use |
| --- | --- | --- |
| `paper-ready` | Reviewed benchmark inputs, selected seed files, prompts, benchmark manifests, benchmark statement reviews, and included-capability reviews. | Cite as provenance or benchmark construction evidence when manifest hashes match the current files. |
| `diagnostic` | Pilot summaries, weak-modality probe summaries, prompt-sensitivity summaries, logprob probes, and external-probe comparison tables. | Use for orientation, debugging, or threats-to-validity discussion; do not cite as final results. |
| `stale` | Checked metric snapshots, preliminary/final result tables, and legacy external probe reports with confidence-scale blockers. | Replace with outputs from a clean post-fix full run before using as paper-facing evidence. |

When in doubt, final paper claims should come from `outputs/evaluation_<dataset>_<variant>_<run_id>/` generated by `scripts/generate_evaluation_analysis.py` after registry, construct-review, confidence-scale, and stale-prompt checks pass, and from the cross-cell tables written by `scripts/export_paper_tables.py`.

## `paper_*` Snapshots

`generate_evaluation_analysis.py` works on **one** cell (dataset x variant x run). The `paper_*` files are the cross-cell layer: they read the per-cell snapshots and produce the tables a paper actually prints.

`scripts/export_paper_tables.py` writes:

| File | What it holds |
| --- | --- |
| `paper_per_model_modality_table.csv` / `.md` | Per-model breakdown by source modality condition: label accuracy, strict and broad text strengthening, high-confidence share, answer length. |
| `paper_per_model_headline.csv` / `.md` | One row per model, with seed-clustered 95% CIs on strict and broad strengthening. Strict strengthening ranges from 0.3% (`glm-4.7`) to 16.9% (`kit.gemma4-31b-it`). |
| `paper_headline_bootstrap_ci.csv` | Pooled headline intervals: strict [8.2%, 9.0%], broad [13.2%, 14.4%]. |
| `paper_snapshot_provenance.json` | Contributing run ids, input file SHA-256 hashes, aggregation mode (pooled vs macro-of-cells), exporter version. |
| `*_regenerated.csv` | Per-cell snapshots re-derived from the raw outputs, written next to the shipped file so the two can be diffed. Pass `--overwrite-snapshots` to replace the shipped file instead. The shipped snapshots currently match their regenerated counterparts bit for bit. |

A table without its entry in `paper_snapshot_provenance.json` is not citable. Aggregation rules are specified in `docs/aggregation.md`.

`scripts/aggregate_paper_headline_metrics.py` re-derives the same headline aggregates and accepts `--regenerate-snapshots`, `--models`, `--cell`, and `--bootstrap-samples` for scoping a check to a single model or cell.

Root-level `paper_*` files that predate the exporter are diagnostic/stale; regenerate them before citing (see `TODO.md`, section E).

## Template Inventory

`modality_template_inventory.csv` / `.md` list every source-statement template used to build the benchmark: the four main conditions, the `SHALL` robustness swap, and the four weak-intent phrasing-probe templates, each with an example realisation. Generated by `eval_utils.write_main_modality_template_inventory`; described in `docs/experimental_setup.md`.

## Tracked here

- **Benchmark manifests** (`benchmark_manifest*.json`) with SHA-256 hashes of every seed, prompt, and benchmark CSV consumed by a run.
- **Benchmark statement reviews** (`benchmark_statements_review*.csv` and matching `.md`) — the human-readable review of generated variants per dataset and modality variant.
- **Included-capabilities reviews** (`included_capabilities_review*.csv` and matching `.md`).
- **Pilot and probe summaries**:
  - `pilot_results_summary.md`
  - `prompt_sensitivity_summary.csv`, `task2_prompt_sensitivity_summary.csv`
  - `weak_modality_probe_summary.csv` / `.md` — four weak-intent phrasings, `qwen/qwen3.5-9b` only, 20 pilot seeds; 100% strengthening on all four templates.
  - `weak_modality_template_sanity_check.csv` / `.md`
  - `modality_template_inventory.csv` / `.md`
  - `logprob_probe.json`
- **External AI service probe** results under `outputs/external_ai_service_probe/` (evaluation Markdown, confusion matrices, source-condition summaries, comparison).

Checked metric snapshots and legacy external-probe reports are diagnostic/stale unless they are explicitly promoted in Git after regeneration under the current confidence contract from a complete post-fix run.

## Local-only

Run-specific analysis directories (`outputs/evaluation_<dataset>_<variant>_<run_id>/`), capability-seed agent-repair artifacts, qualitative example exports, and preliminary tables are gitignored. Root-level `paper_*` metric snapshots are local-only by default and are promoted to Git only once regenerated by `scripts/export_paper_tables.py` with their provenance JSON alongside. They are reproducibility evidence and are promoted to Git only when they become paper-facing.

See `.gitignore` for the precise allow-list, and `docs/repository_layout.md` for the variant-suffix convention used across these files.
